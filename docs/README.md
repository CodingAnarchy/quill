Quill — Documentation

This directory holds Quill's documentation. The user guides below cover how to
use the editor; the design-spike notes further down are internal working notes
kept for history, not user-facing guides.

## User guides

- [`guide.md`](guide.md) — the in-app F1 guide: the full tour of writing,
  navigation, chapters, and export.
- [`configuration.md`](configuration.md) — the global settings reference (the
  home config file: editor, theme, AI, keybindings, and more).
- [`export.md`](export.md) — export and publishing: formats, the `[style]` /
  `[print]` design system, preflight, the KDP / IngramSpark bundle, samples, and
  review copies.
- [`ai-features.md`](ai-features.md) — the opt-in AI assistance: what it does,
  the privacy model, and the backends.
- [`version-control.md`](version-control.md) — drafts, milestones, history, and
  sync.
- [`performance.md`](performance.md) — performance characteristics and tuning.
- [`progress-reports.md`](progress-reports.md) — word-count goals, deadlines, and
  progress reports.
